# Erratum: Phase 2 P2-D regenerate_noises result wording

The original `PHASE2_P2D_REGENERATE_NOISES_RESULT.md` contains wording that says the left trials did not all switch to the required positive early angular sign.

That sentence is incorrect.

Correct interpretation:

- All three Candidate C left trials had positive first-two-second median angular sign.
- All three Candidate C right trials had negative first-two-second median angular sign.
- The first individual angular command was positive for both sides.
- The first-two-second median direction, not one first sample, is the intended directional metric.
- Candidate C still failed because all six trials timed out outside the 0.25 m XY goal tolerance, not because the left early median sign failed.

This erratum preserves the original report and corrects the interpretation without silently rewriting historical evidence.
